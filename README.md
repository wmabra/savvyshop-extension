# SavvyShop 🛍️

Chrome extension that auto-detects product pages across open tabs and compares them with AI recommendations.

## How it works
1. Open 2+ product pages on Amazon, Walmart, Target, Best Buy, etc.
2. SavvyShop auto-detects them and shows a badge count
3. Click the extension → side panel with full comparison
4. AI recommends the best buy based on price, ratings, and value

## Install (developer mode)
1. Go to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" → select this folder
